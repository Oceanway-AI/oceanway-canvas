# Studio 首发入口合同

首发以 Platform 身份、素材、文本/图片/视频、原生 Pi Agent、画布与任务恢复为验收范围。保留其余 OAC 创作源码，未接通入口不挂载实际业务页面，也不启动旧插件状态迁移或供应商配置导入。

| 入口 | 首发状态 |
| --- | --- |
| 创作首页、画布、素材、任务、平台账号资料、模型默认值和本地偏好 | 开放对应的已接通路径，仍需真实服务验收 |
| 短剧、电商、独立图片/视频工作台、技能工作台、插件、返利、旧管理后台 | 暂不可用；直接 URL 同样受限，不能因平台管理员角色重新开放 |
| 外部工作流、供应商素材库、旧提示词模板/反馈/诊断/Agent 记忆设置 | 暂不可用，设置页不挂载其组件、不发其后台请求 |
| 公开画布分享及匿名素材读取 | 在独立素材分享授权接通前整体暂不可用；不复用登录者素材委托，也不调用旧资源交付 |
| Agent 内嵌技能目录、已安装技能读取/添加/移除、自动/手动使用模式 | 复用原生 Skills 服务及账号权限；独立技能工作台、外部安装、发布与管理写入继续暂不可用 |

后端发布功能开关覆盖旧库配置，未接通能力不能被旧开关重新启用。前端边界在真实子页面挂载前展示状态及返回画布入口；服务端路由白名单仍是最终权限边界。其他未开放生成种类、供应商私有操作由现有 Studio 执行合同拒绝。纯本地编辑逻辑继续保留。

先验证失败：功能标志不得公开尚未接通的能力；Studio 分享接口不能创建分享记录或访问旧匿名资源路径；真实 React 路由边界不得挂载受限子组件。然后实现门禁并回归既有身份/画布/任务路径。

2026-11-09 C4：Agent 媒体报价未提交最高额度时仅预览，不创建可执行报价或持久审批事件；取消额度弹窗后恢复不得隐式获得批准权。明确确认额度后仍走原审批 CAS、冻结参数、根授权及原 Task。规范见 Docs PLAT-04-029 §9，免费和真实验收分别记录。
