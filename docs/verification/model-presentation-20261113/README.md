# Studio model presentation verification — 2026-11-13

Source baseline: `00396bc`, isolated branch
`codex/studio-model-groups-20261113`. The pre-existing model-grouping work in
this branch is retained and extended. Normative requirements are
OceanWay Docs PLAT-02-061/062/063 and PLAT-04-030, WP-PLAT-018.

## Implemented path

- The existing Studio catalog route reads Platform through the actually
  published `platformclient v0.1.0`. Exact-ID selection still uses its typed
  catalog; response extensions carry the full original model JSON and server
  groups without changing SDK dependency pins or committing a local replace.
- Missing, extra or duplicate wire models and hidden group members are rejected. JSON numeric
  capability values and exact decimal price strings are preserved.
- The existing model selector consumes the shared group/model presentation:
  availability, weighted health, condition-specific prices, full descriptions,
  editorial tags and published capability summaries. Text uses series; media
  uses logical models. Missing identities remain exact-ID singletons.
- Search includes model IDs, labels, groups, descriptions and tags. Price
  conditions, introductions and hourly health are available by keyboard focus.
  Missing samples show no data, not zero-percent failure. Historical failures
  do not change callability.
- Directory loading has explicit loading/empty/error states and retry. Cached
  system rows are removed before refresh and on failure. Custom user channels
  remain. Session generations and single-flight requests prevent old responses
  from repopulating a new or logged-out session.
