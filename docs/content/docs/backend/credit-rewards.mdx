# 账号与权益

Studio 的账号、会员、余额、可用权益和办理能力由 OceanWay Platform 提供。账户面板展示当前空间摘要，通过 Platform Console 导航办理充值和订阅。

Studio 已退出注册赠送、签到积分、独立钱包、兑换码与本地支付插件。创作提交使用 Platform 的预览、授权和结算合同，当前价格无法确认时保留不可用状态。

接口与错误处理见 [HTTP API](./http-api)，持久化范围见 [后端数据库](./backend-database)。
